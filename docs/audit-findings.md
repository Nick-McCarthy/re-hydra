# re-hydra audit findings

Plan: [audit-plan.md](audit-plan.md). Phase notes: [audit/phase-1-2.md](audit/phase-1-2.md). Invariants `I1`–`I12` are defined in the phase 1–2 notes.

Verdict: CONFIRMED means the path was read end to end in the code, or a test reproduced it. PLAUSIBLE means a reproduction is still needed.

What changed for each fix is in [audit-changelog.md](audit-changelog.md).

Correction (2026-11-22): A-017 first said the docs were wrong about `R_MIPS_26` blanking the whole `jal`. They were right for the old code. A 26-bit width blanked the whole word. The A-006 fix changed that behavior, and the docs were updated with it.
